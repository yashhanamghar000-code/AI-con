# AI-CON: MHT-CET Admissions Counselling LoRA Adapter

**AI-CON** (AI Consultant for Education) is an evidence-grounded education counselling assistant designed for Maharashtra engineering admissions governed by the official State Common Entrance Test Cell Centralized Admission Process (MHT-CET CAP).

This repository contains the fine-tuned **LoRA (Low-Rank Adaptation)** adapter trained on top of [`TinyLlama/TinyLlama-1.1B-Chat-v1.0`](https://huggingface.co/TinyLlama/TinyLlama-1.1B-Chat-v1.0).

---

## 1. Core Architectural Principle: Train Behaviour, Never Facts

In admission counselling systems, memorizing cutoff figures in model weights leads to catastrophic hallucinations and stale advice. This model was fine-tuned under the **Cardinal Rule of AI-con**:

1. **Facts Are Never Learned in Weights:** Ranks, percentiles, intake numbers, seat counts, and fees change every single academic year.
2. **Dynamic Evidence Grounding:** All factual data is supplied dynamically into the context prompt at inference time via deterministic lookup from verified institutional records.
3. **Behavioural Fine-Tuning Only:** The LoRA adapter trains strict behaviour:
   - **Bracketed Evidence Citation:** Attaching exact `[evidence_id]` citations to all generated statements.
   - **Abstention on Missing Evidence:** Refusing to invent numbers when a requested category, branch, or round is not in the supplied evidence (`status: insufficient_evidence`).
   - **Metric Independence:** Treating merit ranks (integers) and percentiles (floats) as mathematically distinct metrics that must never be conflated.
   - **Non-Guarantee Disclaimers:** Explicitly notifying candidates that past cutoffs represent historical round outcomes, not admission guarantees.

## 3. Training Dataset & Procedure

The model was trained on the verified conversational SFT dataset generated by the AI-con data pipeline:
- **Dataset Composition:**
  - **Grounded Cutoff Examples:** Citing round, stage, quota, closing rank, and closing percentile.
  - **Structured Abstention Examples:** Structured refusal when queried facts are absent from the context.
  - **Qualitative Institutional Profiles:** Affiliation, ownership, location, and autonomy status from 1,041 verified engineering colleges in Maharashtra.
- **Data Format:** Chat template messages format (`system`, `user`, `assistant`).
- **Optimization:**
  - Optimizer: AdamW
  - Initial Learning Rate: `2e-4` (Linear schedule with warmup)
  - Batch Size: `2` (Gradient accumulation steps enabled)
  - Precision: FP32
  - Epochs: `1`
  - Validation: Monitored on held-out validation split. Training loss reduced from `5.635` to `2.805`; validation loss improved from `4.103` to `3.690`.

## 4. How to Use the Adapter

You can load and use this adapter using Hugging Face `transformers` and `peft`:

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM
from peft import PeftModel

# 1. Load Base Model and Tokenizer
base_model_id = "TinyLlama/TinyLlama-1.1B-Chat-v1.0"
adapter_id = "your-username/AI-CON-MHT-CET-Counselling-LoRA"

tokenizer = AutoTokenizer.from_pretrained(adapter_id)
base_model = AutoModelForCausalLM.from_pretrained(
    base_model_id,
    torch_dtype=torch.float32,
    device_map="auto"
)

# 2. Attach LoRA Adapter
model = PeftModel.from_pretrained(base_model, adapter_id)

# 3. Format Admission Query with Supplied Evidence
prompt = """<|im_start|>system
You are an admission decision-support assistant for Maharashtra engineering colleges. Use only the supplied evidence. Cite evidence IDs in [brackets]. Never promise admission. If evidence is missing, respond with status=insufficient_evidence and say exactly what is missing.<|im_end|>
<|im_start|>user
EVIDENCE:
[2024-25:01002:0100219110:state_level:GOPENS:R1:S1] 2024-25 CAP round 1 stage 1 | State Level | GOPENS: closing rank 34240, percentile 88.5013511

QUESTION: What was the GOPENS cutoff for Civil Engineering at Government College of Engineering, Amravati in 2024-25?<|im_end|>
<|im_start|>assistant
"""

# 4. Generate Grounded Response
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
outputs = model.generate(**inputs, max_new_tokens=100, do_sample=False)
response = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(response)
```

## 6. Limitations & Disclaimer

- **Decision Support Only:** This system is an advisory decision-support tool. It does **not** make admission offers or guarantee seat allocation in any college or round.
- **Official Verification Required:** Cutoff ranks fluctuate each year depending on student choices, exam difficulty, seat matrix, and government reservation policies. Always confirm against the official Maharashtra State CET Cell portal ([cetcell.mahacet.org](https://cetcell.mahacet.org)) before making admission decisions.
